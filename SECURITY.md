# Security and authorized use

VulnSight is intended for:

- Explicitly authorized security testing
- Self-authored or intentionally vulnerable training applications
- Academic / graduation-project demonstrations

## Rules of use

1. Obtain authorization before testing any system.
2. Configure explicit in-scope origins; do not treat discovered URLs as permission.
3. Prefer lab / loopback targets for demos.
4. Do not use this tool to attack third-party production systems.
5. Do not commit secrets, session cookies, or personal data into findings or reports.

## Reporting security issues in this repository

If you discover a vulnerability in VulnSight itself (for example unsafe report rendering or scope bypass), open a private security advisory or contact the maintainers through the GitHub repository owners.
