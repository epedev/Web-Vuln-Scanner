VulnSight

A modular CLI web vulnerability scanner for authorized local assessments: reconnaissance, XSS, SQL injection, command injection, access control, and professional HTML, Markdown, and PDF reporting.

Start scanning Architecture OWASP Top 10

One clear workflow

Authorize a local target, run every module, open a self-contained HTML report.

01

Install

pip install -e ".[dev]" then vulnsight doctor.

02

Authorize

vulnsight init-project writes a project JSON with explicit permission.

03

Scan

vulnsight scan --project myproject.json runs all detection modules.

04

Report

Open reports/vulnsight_report.html — filterable findings + remediations.

Five-person modular design

Each module stays independently testable and integrates through shared finding contracts.

Recon

Crawler

Same-origin crawl map with forms, params, and scope checks.

Inject

SQLi / Cmd

Bounded local checks with evidence vs noise discipline.

XSS

Reflected / Stored

Marker-first analysis; confirmation is earned, not assumed.

Access

IDOR / BAC

Role and object-level authorization boundary probes.

Report

CVSS + HTML

Canonical schema, conservative dedupe, honest limitations.
