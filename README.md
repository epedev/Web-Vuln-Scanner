# Web-Vuln-Scanner

Modular web vulnerability scanner for authorized / lab security testing.

## Modules

| Folder | Description |
|--------|-------------|
| [`xss_module/`](xss_module/) | Cross-Site Scripting (XSS) detection engine |
| [`sqli_&_command_module/`](sqli_&_command_module/) | SQL injection and command injection checks |
| [`reporting_module/`](reporting_module/) | VulnSight reporting & CVSS v3.1 risk-scoring engine |

See [`reporting_module/README.md`](reporting_module/README.md) for report generation commands.
